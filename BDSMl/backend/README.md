# Backend RISC-V 64

Каркас задания 3. План и критерии готовности: [TASKS_riscv.md](../TASKS_riscv.md).
Библиотека `BDSMl.backend` пока не подключена к CLI.
`Codegen.generate` возвращает явную ошибку до реализации генерации.
Остальные модули содержат только описание ответственности. Основные решения
по ABI записаны в [abi/ABI.md](abi/ABI.md): Linux RV64GC, стандартный ABI
`lp64d`, значения по 64 бита и runtime замыканий. Объявления runtime находятся
в [runtime.h](../runtime/runtime.h). Общие константы доступны через
`BDSMl_backend.Abi.Abi`; библиотека backend собирается, реализация генерации
и runtime ещё предстоит.

| Файл | Назначение | Задача |
|---|---|---|
| `abi/abi.ml/.mli` | представление значений, аргументы, результат, сохраняемые регистры | 0 |
| `assembly/asm.ml/.mli` | регистры, инструкции, операнды, метки и директивы | 3 |
| `assembly/asm_printer.ml/.mli` | печать GNU-совместимого ассемблера | 3 |
| `lowering/symbols.ml/.mli` | имена символов, метки, арности и глобальные определения | 3, 6 |
| `allocation/frame.ml/.mli` | размещение параметров и локальных значений, стековый кадр | 4 |
| `lowering/emit_expr.ml/.mli` | генерация операций, привязок и ветвлений ANF | 5 |
| `lowering/emit_call.ml/.mli` | прямые вызовы, функциональные значения, обращение к runtime | 6 |
| `codegen.ml/.mli` | сборка программы, глобальные инициализаторы и точка входа | 5, 9 |

Runtime находится в [../runtime/](../runtime/), исходники сквозных тестов —
в [../test/riscv/](../test/riscv/). Инструменты и планируемая команда статической
сборки через RISC-V GCC и запуска через QEMU описаны в [abi/ABI.md](abi/ABI.md).
Внутренние интерфейсы модулей backend ещё предстоит реализовать.

Каталоги объединяют общие задачи: `abi/` — соглашения, `assembly/` —
представление и печать ассемблера, `allocation/` — размещение значений,
`lowering/` — перевод ANF в инструкции. `Codegen` остаётся точкой входа.
Dune использует `include_subdirs qualified`, как frontend и middleend:
например, принтер будет доступен как `BDSMl_backend.Assembly.Asm_printer`.
