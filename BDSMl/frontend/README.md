# Фронтенд

Оба парсера строят общее дерево `Ast.program`:

| Реализация | Лексер | Входная функция |
| --- | --- | --- |
| Рекурсивный спуск | `LL_parser/lexer.ml` | `LL_parser.Parser.parse_string_LL` |
| Menhir + ocamllex | `LR_parser/lexer.mll` | `Parse.parse` |

`LL_parser` содержит ручной лексер и рекурсивный парсер. В `LR_parser` находятся
исходники ocamllex (`lexer.mll`) и Menhir (`parser.mly`); Dune генерирует из них
модули внутри пространства имён `LR_parser`.

Грамматика Menhir использует общий тип токенов `Tokens.token` через
`--external-tokens Tokens`. `LR_parser.Lexer.tokenize_lazy` выдаёт токены
по запросу, включая `TEOF`; `LR_parser.Lexer.tokenize` собирает их в список.
Оба парсера читают токены из соответствующих ленивых последовательностей.
`Parse.parse` запускает Menhir и возвращает ошибки
как строки, сохраняя прежний интерфейс `(Ast.program, string) result`.

В `LR_parser/parser.mly` сохранены исходные правила и приоритеты Menhir;
имена токенов приведены к `Tokens.token`, а `PWild` заменён на новый узел AST
`PUnderscore`.
Добавлен разбор токена `TUnit`. Как и прежде, восходящий парсер допускает пустую
программу и соседние определения `let` без `;;`. Оба парсера принимают unit с
пробелами между скобками, например `( )`, в выражениях и шаблонах.
Оба лексера поддерживают вложенные комментарии `(* ... *)`.

Из корня репозитория (нужны Dune >= 3.24 и зависимости проекта):

```sh
dune build BDSMl/frontend/frontend.cma
dune runtest BDSMl/test
```

Тесты сравнивают токены и AST обоих вариантов, проверяют CPS-факториал,
CPS-Фибоначчи, приоритеты, ошибки и 4000 случайных примеров QCheck.

## Ассоциативность операторов

Стандартная конфигурация нисходящего парсера совпадает с OCaml и Menhir:
`&&` и `||` правоассоциативны, остальные бинарные операторы из подмножества
левоассоциативны. Для эксперимента ассоциативность LL-оператора можно изменить
во время запуска, не генерируя парсер заново:

```sh
dune exec BDSMl -- --parse '8 - 3 - 1' --operator-assoc minus:right
dune exec BDSMl -- --parse 'true || false || true' --operator-assoc or:left
```

Доступные имена: `plus`, `minus`, `mul`, `div`, `equal`, `not-equal`,
`greater`, `less`, `greater-equal`, `less-equal`, `and`, `or`. Флаг можно
указывать несколько раз. Он поддерживается только с `--parser ll`; попытка
использовать его с `--parser lr` завершается ошибкой. Без флага используется
стандартная грамматика.
