                        _⪯v

           C(p1 ; … ; pa ) ⪯ C(v1 ; … ; va )                т.т.к. (p1 ; … ; pa ) ⪯ (v1 ; … ; va )

Decision Trees



  Определение (Диаграмма решений)
  Это дерево (DAG), где в листьях результаты, в узлах вычисляется некоторые
  выражения, а на ребрах написаны возможные его значения


  Для нашего случая в листьях результат сопоставления, в узле
  подвыражение, а на ребрах названия конструкторов

  Отличительным свойством является отсутствие повторных проверок
