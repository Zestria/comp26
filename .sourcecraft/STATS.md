# Фильтрация статистики

`dune.sh stats` определяет компилятор через `COMPILER` либо автора PR и
`teams.yml` и вызывает `git-user-stats`, передав имя компилятора в `LOGDIR`.
Сам `git-user-stats` читает ники участников выбранной команды из `teams.yml`
и добавляет фильтр авторов к параметрам `git log`.
В `git-author-emails.json` можно указать список Git-email для каждого ника.

Если email заполнены для всех участников команды, в `git log` передаётся
фильтр по этим адресам. Сопоставление точное, без учёта регистра; допускается
несколько адресов одного участника. Если хотя бы один участник не заполнен,
сохраняется прежний отчёт по всем авторам папки, с пояснением в stderr.
Отсутствие таблицы также включает прежний режим. Некорректный JSON или формат
заполненных адресов считается ошибкой конфигурации.

Формат итоговой таблицы не меняется, включая колонку Email. Сборка и Zanuda
не изменены. Имена команд не зашиты в код; соответствия пока
заполнены только для BDSMl, остальные команды могут добавлять свои позднее.
Прямой запуск `git-user-stats` с `LOGDIR` использует тот же фильтр. Без `LOGDIR`
сохраняется подсчёт по всем авторам репозитория без чтения таблицы команд.

Проверки из корня репозитория:

```sh
python3 -B -m unittest discover -s .sourcecraft -p 'test_stats_*.py'
COMPILER=BDSMl sh .sourcecraft/dune.sh stats
LOGDIR=BDSMl bash .sourcecraft/git-user-stats
```

Полный запуск использует уже имеющиеся в CI `yq` (обёртку над jq), GNU awk
и Python 3. Новые Python-скрипты используют только стандартную библиотеку.
