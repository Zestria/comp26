# Домашка по компиляторам

## Структура

В отдельных директориях находятся реализации компиляторов.
Все компилятора объединены в один dune project, на каждый компилятор должен быть отдельный dune package.
Тестироваться будет вот так: `dune b -p demo` или `dune test -p demo` (при условии, что demo --- название компилятора).

Все компиляторы должны запускаться с помощью команды `dune exec demo/compiler.exe`.

### Необходимые опции командной строки

У всех будут требования на опции командной строки (напишу потом).

* Чтобы показать, что menhir не очень, реализуйте в нисходящем парсере (на выбор)
  * идентификаторы, слипшиеся с ключевыми словами.
  * переопределние арности/ассоциативности операторов.

  Дополнительный синтаксис должен включаться явно опцией командной строки.
