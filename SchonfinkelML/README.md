# SchonfinkelML

## Syntax analysis
 We are using two parsers: LR(1) (Generated by Menhir) and hand-written recursive descent.
 Check out `benchmark/README.md` for more info about performance comparison of these two parsers

## Middleend

The compiler pipeline is `parsing -> closure conversion -> lambda lifting`.

## Prerequisites
You need the following in order to use SchonfinkelML compiler:
  - `qemu`, `riscv-binutils`
  - `gcc` to compile runtime :) 

Here how to install them if you are on Debian/Ubuntu:
``` bash
sudo apt install -y \
   binutils-riscv64-linux-gnu qemu-user gcc
```

The compiler returns assembly file as a result, to get complete riscv64 executable run these commands:
``` bash
# Your input is `input.S`
riscv64-linux-gnu-as -march=rv64gc input.S -o temp.o
riscv64-linux-gnu-ld temp.o -o file.exe
qemu-riscv64 -L /usr/riscv64-linux-gnu -cpu rv64 ./a.out
```


## How to run

```
dune build -p SchonfinkelML
dune test  -p SchonfinkelML
dune exec -p SchonfinkelML SchonfinkelML/compiler.exe -- <input.ml>            # top-down
dune exec -p SchonfinkelML SchonfinkelML/compiler.exe -- -parsing menhir <input.ml>
dune exec -p SchonfinkelML SchonfinkelML/compiler.exe -- --stop-after anf <input.ml>
```

The result goes to stdout by default; `-o <file>` writes it to a file and
`-o -` explicitly selects stdout.
