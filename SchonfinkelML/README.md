# SchonfinkelML

## Syntax analysis
 We are using two parsers: LR(1) (Generated by Menhir) and hand-written recursive descent.
 Check out `benchmark/README.md` for more info about performance comparison of these two parsers

## How to run

```
dune build -p SchonfinkelML
dune test  -p SchonfinkelML
dune exec SchonfinkelML/compiler.exe -- <input.ml>            # top-down
dune exec SchonfinkelML/compiler.exe -- --bottom-up <input.ml>
```
